    This gameplay guide aims to provide you with everything you need to know in an optimised manner in order to simplify the road to 100% trophies. That's the platinum and the DLC trophies combined into an all-in-one walkthrough that focuses on the bare minimum requirements.

    An objective/checklist hybrid layout is used along with manually edited maps with markers to better give you directions of what to do and where. More detail is given where required and videos are provided in each section with commentary if watching the route via gameplay is more your thing or you just for extra confirmation.

    The FAQ section below should answer any questions you have before you begin, so please check that first and for anything else, you will likely find your answer while using the guide.

    Above all, just enjoy the game!

    FAQ


    How long will it take for me to get 100% trophies using this guide?

    Not long at all, going solely with the route outlined here, skipping cutscenes and using assist mode, you are looking at approximately 5 - 10 hours for 100% trophies. It all boils down to you though and how you choose to play through it, this guide just provides a minimum.

    Can I use this if i'm only looking for the platinum?

    Yes and no, acquiring the platinum in the base game by itself requires more tasks to be completed in the base game. However, combining the base game trophies with the DLC trophies actually removes a lot of the base game grinding as DLC requirements will naturally fulfil a lot of the base game requirements also. Some players may say the DLC is grindy, but combining it with the base game along an optimal route, removes almost all the grinding!

    I heard this game has Assist Mode, what exactly are the options and does it disable trophies?

    No they don't, you can use every single cheat, and trophies still pop, that's PS4 and PS5!! Below is a full list of the cheats you can activate, you access them via Options > Gameplay.
    • Assist Mode.
      • Disabled/Enabled.
      • Enhanced Aim Assist.
      • Aim Snapping.
      • Energy Recovery Multiplier.
      • Damage Reduction Multiplier.
      • Ammo Recovery Multiplier.
      • Immortality.
      • One-hit Kills.

    Is the game difficult without Assist Mode?

    It can be if you don't build yourself well. The game features weapon and physical mods which are basically perks you can slot. These are random drops mostly and with no healing consumables, you can only heal via mod perks, enemy drops and by using control points, so having some good healing perks during battle can really help. Damage is a big factor as well, later in the game, enemies will become stronger which will usually require good use of launch along with good damage mods on your weapons to defeat enemies quickly. Just remember, you have the option to use Assist Mode whenever you want, should you wish to!

    Do we need to collect all file collectibles?

    No you don't actually! For the platinum trophy, you need 120 collectibles, and for 100%, you need to collect 57 collectibles in the Foundation DLC and approximately 55 in the AWE DLC. Because the base game gives you approximately 65 files naturally, with the DLC collectibles as well, you don't actually have to collect extra in the base game content, as you get the remaining files from the DLC. If going for platinum only, you would need to collect extra in the base game content, but going for 100% trophies as this guide does, you won't need to!

    What about the Ability Points, i've read we need to complete all base game content to get enough?

    Again, if going for platinum only, yes, you would need to complete all the base game content to acquire enough, but with the DLC included, you don't. Completing only the trophy related side missions and the story in the base game will earn you about 60 ability points, and you can actually get the rest while completing the DLC trophies. Altogether, with the story, the trophy related side missions and the DLC trophies, you acquire approximately 107 ability points. 

    In regards to upgrading weapons, I noticed there is a weapon upgrade trophy in the base game, and the DLC, can I combine these 2?

    Yes, upgrading the DLC weapon will pop the base game upgrade trophies as well! However, if you are playing without assist mode, you may want to upgrade base game weapons along the way to make the game easier, if you do this, just make sure you keep 1 x untapped potential for the DLC weapon as they only drop from base game bosses.

    The map is pretty confusing to use, can you explain it a bit more?

    It is, this game has a rather strange map, it does become easier to navigate over time of course, but can still be confusing. If you think of normal maps where different floors in a building are divided so you can clearly use it, well here, those different floors are stacked. Rather than strip each floor out and give them there own page, they are stacked into multiple layers making the highest floor always more visible and hiding the floors below.

    This sounds like a bit of a nightmare to navigate, but to compensate for the multiple layers, each floor has a different shade to it, slightly hinting at which level it is. A darker shade means it is lower and a light shade means it is higher. There are instructions here to help you navigate, along with commentated videos which copy the route here, so if you are really struggling to identify an objective and haven't been using the videos, you can briefly refer to the footage just to get a clear idea of where to go.

    Just like the different shades of floor layers, the icons placed on the maps used for this guide have also been given different shades. Most the time it will be clear where a map marker is as you should already be going that way, but if not, look closely or even zoom in on a map (just click the image) and you should be able to identify a marker location via the shade of it.

    Maneki-Neko #6

    This particular cat is very tricky to acquire and may take a bit of practice!

    You may have noticed on the way up from floor 5, that some hiss nodes appeared briefly and what you need to do to acquire this Maneki-Neko is to destroy all 4 of those hiss nodes in one go. They only appear when going from floor 5 up to floor 6. There will be a very short time to position yourself ready for the next node and each node must be melee'd.

    To make it even worse, just before the hiss nodes appear, there will be no lighting, meaning it's quite difficult to position yourself ready, the only way is to quickly position yourself before the node light dissipates. It is possible to get them with an explosive, but it makes it even trickier so stick to melee.

    From floor 5 to 6, they will appear in this order, there is a delay of about 5 - 10 seconds before the first node appears once you press the lift button.
    1st node > South wall.
    2nd node > West wall.
    3rd node > North wall.
    4th node > East wall.

    They appear in a clockwise manner beginning from the south side,  you will have a second to hit each one and then about 2 seconds to position yourself ready for the next node before it appears. It may take a few attempts, but you can rest assured that it doesn't take insane reflexes and speed, so shouldn't consume too much time.

    Once you have done all 4 correctly, Maneki-Neko #6 will appear at the top in front of the elevator, be sure to collect it!
