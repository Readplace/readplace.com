Import links into your reading queue

Paste a link to any page — a newsletter issue, a blogroll, a bookmarks export — or upload the file itself, and Readplace pulls every URL out for you to review before saving. No account needed to start; you sign up only when you save.

How it works

  1. Paste a link or upload a file. Any page URL works — a newsletter issue, a blogroll, a link roundup — as does any text-shaped file: HTML, JSON, CSV, or plain text.
  2. Review the extracted links. Readplace lists every URL it found; untick the ones you don't want.
  3. Sign in to save. Saving the selection to your reading queue is the only step that asks for an account.

What you can import

  • Newsletters and blogrolls — paste the page URL and Readplace collects every link it points to.
  • Browser bookmarks — upload the HTML file Chrome, Firefox, Safari, or Edge exports.
  • Pocket exports — upload the HTML file Pocket produced. Lost it? The Pocket recovery guide covers getting your list back.
  • Anything text-shaped — OPML, CSV, Markdown, notes; any file with http(s):// URLs in it.
